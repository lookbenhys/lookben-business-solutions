# LOOKBEN · Gestión Integral de Operaciones

Nueva landing independiente de LOOKBEN.

## Estructura

- `index.html` — página principal
- `styles.css` — estilos
- `app.js` — interacción y modales
- `assets/logo.png` — identidad visual

## Publicación en GitHub Pages

Crear un repositorio NUEVO, por ejemplo:

`lookben-operaciones`

Subir el contenido de esta carpeta a la rama `main`.

Luego en GitHub:
Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` → `/ (root)` → Save.

La URL quedará con el formato:

`https://lookbenhys.github.io/lookben-operaciones/`

Este proyecto no modifica el repositorio actual `lookbenhys.github.io`.
